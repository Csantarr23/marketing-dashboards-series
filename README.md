Abrir cualquier `.html` en el navegador — no requiere servidor ni dependencias.

- Fondo `#08080F` · Acento `#FF4B14` · Canvas 1080×1920px
- Auto-escala al viewport
- Constantes editables al inicio del `<script>` de cada archivo
